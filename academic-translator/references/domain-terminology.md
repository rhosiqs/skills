# Domain reference: plant science, biotech, bioinformatics, CS, agriculture

These are the fields this skill serves most. Load the sections that match the source text. Entries are chosen for one property: getting them wrong produces output that passes a fluency check and is still wrong.

Where a term differs between Taiwan and Mainland usage, the Traditional form is given first and the Simplified second, separated by a slash. Pick by the user's variant and hold it for the whole document.

## Nomenclature and typography (applies to all biological fields)

This apparatus is not language. It is copied, not translated.

- **Binomial names** stay Latin and italic in both directions: *Arabidopsis thaliana*, *Oryza sativa*, *Botrytis cinerea*. Chinese papers usually give the Chinese common name with the Latin binomial in parentheses on first mention — 阿拉伯芥（*Arabidopsis thaliana*）. Going into English, drop the Chinese name and keep the Latin. Going into Chinese, add the conventional Chinese name if one is established and keep the Latin; if no settled Chinese name exists, keep the Latin alone and say so in the notes.
- After first mention the genus abbreviates: *A. thaliana*. Do not abbreviate at the start of a sentence, and do not abbreviate two genera to the same letter in one paper.
- **Authority citations** (L., DC., Hook.f., Mill.) are part of the name. Never translate, never drop, never italicise.
- **Infraspecific ranks**: subsp., var., f. are roman, the epithet italic — *Brassica oleracea* var. *italica*. 變種/变种 is var. (botanical variety) and 品種/品种 is usually cultivar. These are not the same rank and conflating them is a substantive error.
- **Cultivars** take single quotes, roman type, and no translation: *Malus domestica* 'Fuji', 'Tainung No. 1'. Chinese writes 品種「台農1號」 with corner brackets; convert the brackets, keep the name. Do not render a cultivar name phonetically or semantically — 'Fuji' is not 'Rich Wealth'.
- **Trade designations and PVP names** differ from cultivar names; keep whatever form the source used.
- **Gene and protein typography.** Gene symbols italic, protein symbols roman. In *Arabidopsis* convention: wild-type gene *AP1* (italic caps), mutant allele *ap1* (italic lowercase), protein AP1 (roman caps). Rice and maize use their own conventions. Preserve exactly what the source did — capitalisation here is data.
- **Sequences, accessions, and identifiers**: GenBank accessions, gene IDs (AT3G54340, LOC_Os01g01010), SNP IDs, plasmid names, strain names (*Agrobacterium tumefaciens* GV3101), and primer sequences are copied character for character.
- **Chemicals, hormones, and media**: IAA, 2,4-D, BAP, MS medium, ½MS, Hoagland's solution. Copied. `MS 培養基` → `MS medium`, not "Murashige and Skoog medium" unless the source spelled it out.
- **Software, formats, and databases**: BLAST, HISAT2, STAR, Trinity, GATK, SAMtools, QIIME2, FASTQ, BAM, VCF, GFF3, NCBI, TAIR, KEGG, GO. Never translated, capitalisation preserved.

`程序` in Taiwanese usage means *procedure* or *process*, not *program*. This is the single most common cross-variant error in CS translation.

Never translate: language names, library and package names, function and variable identifiers, CLI flags, file extensions, error messages, or anything inside code fences. Keep code blocks byte-identical and translate only the surrounding prose and, if the user asks, the comments.

## Units, measures, and things never to convert

Copy numbers, units, and statistics exactly. Do not convert, round, or normalise unless the user asks, and if they do, apply it consistently and say so in the notes.

- 公頃 ha, 公畝 are, 平方公尺 m². `公斤/公頃` is kg ha⁻¹ or kg/ha — match the target journal's style if known, otherwise mirror the source.
- **甲** is a Taiwanese land unit (≈0.9699 ha) and **畝** is a Mainland one (≈1/15 ha). Neither has an English equivalent. Keep the original with a parenthetical gloss on first use; never silently convert, because the conversion factor differs and readers may need the original figure.
- **台斤** (600 g) and **斤** (Mainland, 500 g) are different masses. Same rule.
- Concentrations: mg L⁻¹, µM, ppm, %(w/v) — copy the notation the source used. `百萬分之一` written out becomes ppm only if the source clearly meant the unit.
- Temperatures, photoperiods (16 h light/8 h dark), and light intensity (µmol m⁻² s⁻¹) are method-critical. Verify every digit at the end.
- Chinese-era or lunar dates and 民國 years in Taiwanese agricultural records: convert 民國 to CE (add 1911) and note the conversion, since leaving 民國 112 in an English paper is unreadable.

## High-hazard terms

These change meaning across these specific fields. Resolve from context before translating; if the context does not resolve it, flag rather than guess.

| Term | The trap |
|---|---|
| fertilization | 施肥 (applying fertilizer) vs 受精 (gamete fusion). Both are "fertilization" in English. In a plant paper either reading is plausible in the same paragraph. |
| 馴化 | acclimatization (of tissue-culture plantlets, of a genotype to a site) vs domestication (of a crop from a wild ancestor). Utterly different claims. |
| vector | 載體 (cloning vector) vs 病媒 (disease vector, insect) vs 向量 (mathematical vector). All three occur in these fields. |
| annotation | 註解/註釋 (genome annotation) vs code comment vs a note on a figure. |
| variety | botanical rank var. vs cultivar vs loose "type". 品種 usually means cultivar. |
| resistance | 抗性 (disease/pest resistance) vs 耐性 (tolerance) vs 電阻. Resistance and tolerance are separate phenotypes and a paper distinguishing them means it. |
| culture | 培養 (cell/tissue culture) vs 栽培 (field cultivation) vs 文化. |
| medium | 培養基 (growth medium) vs 介質 (potting substrate) vs 媒介. |
| 表現 | expression (of a gene) vs performance (of a cultivar or a model). 品種表現 is cultivar performance, not gene expression. |
| significant | statistical significance vs substantive importance. Never blur in either direction. |
| control | 對照組 (control group) vs 控制 (to regulate) vs 防治 (pest control). 病害防治 is disease control/management, not "disease control group". |
| sample | 樣本 (statistical) vs 樣品/試樣 (physical specimen). |
| model | 模式 (model organism, e.g. 模式植物 model plant) vs 模型 (mathematical/trained model). 模式植物 is never "pattern plant". |
| stress | 逆境/胁迫 (abiotic/biotic stress) vs mechanical stress vs psychological stress. |
| population | 族群/群體 (biological or breeding population) vs statistical population. |
| line | 品系 (breeding line, inbred line) vs 線 vs 譜系. |
| generation | F1, F2, BC1 — copy the notation; 世代 alone loses it. |
